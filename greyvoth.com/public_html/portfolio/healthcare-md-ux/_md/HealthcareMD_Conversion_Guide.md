# Converting UX Case Study to Presentation Formats

## How to Create the Final Deliverables

Since I created the content in Markdown format, here's how to convert it to the requested PPTX and DOCX formats:

### For the Presentation Deck (.pptx):

1. **Copy the content** from `HealthcareMD_UX_Presentation.md`
2. **Use a Markdown to PowerPoint converter:**
   - **HackMD or Markdown Slides:** Paste content and export as PPTX
   - **Pandoc:** `pandoc -t pptx HealthcareMD_UX_Presentation.md -o presentation.pptx`
   - **Online tools:** Markdown to PPTX converters

3. **Apply the design theme:**
   - **Color scheme:** Navy blue (#1a365d), white, warm accent (#f59e0b)
   - **Fonts:** Clean, professional (Arial or Calibri)
   - **Layout:** One key idea per slide, section dividers
   - **Medical aesthetic:** Add subtle healthcare icons or imagery

### For the Written Case Study (.docx):

1. **Copy the content** from `HealthcareMD_UX_Case_Study.md`
2. **Use a Markdown to Word converter:**
   - **Pandoc:** `pandoc HealthcareMD_UX_Case_Study.md -o case_study.docx`
   - **Online tools:** Markdown to DOCX converters
   - **Typora or similar:** Export Markdown as Word document

3. **Format professionally:**
   - **Headers:** Use Word's heading styles (Heading 1, 2, 3)
   - **Table of Contents:** Auto-generate from headings
   - **Page breaks:** Between major sections
   - **Professional styling:** Consistent fonts, spacing, and formatting
