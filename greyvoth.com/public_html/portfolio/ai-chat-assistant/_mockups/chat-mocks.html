Focus outlineTab order
01
Close button

First stop when the panel opens. aria-label="Close chat". Esc also closes and returns focus to the launcher.

02
Message log

role="log" with aria-live="polite", so new answers are read without interrupting the member.

03
Links in answers

Descriptive link text, reachable with Tab inside the log.

04
Suggestions

Real <button> elements in a group labeled "Suggested questions".

05
Message input

Labeled "Type your question" for screen readers. Enter sends.

06
Send button

Sits inside the field. aria-label="Send message". Disabled while a message is sending.

—
Typing and contrast

Typing is announced once, "Assistant is typing". Text meets 4.5:1; focus outlines meet 3:1.
